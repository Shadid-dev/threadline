# Utilities

Small helper scripts. Both need a `.env` file in the `threadline` folder containing `GEMINI_API_KEY=your_key` (never upload this file).

- `test_key.py`: checks that your Gemini key works. Run: `python3 utilities/test_key.py`
- `list_models.py`: lists the Gemini models your key can use. Run: `python3 utilities/list_models.py`
