# Team folders

Each person has one folder here. **Put your own work in your own folder.** Nobody else will edit it without asking.

Inside your folder:

- `README.md`: your agent's job, what to upload, and your next steps. Edit it as you go.
- `labs/`: put your Lab 2, Lab 3 and Lab 4 files here (Word/PDF reports, code, zip files are all fine).
- Any new code for your agent can go directly in your folder. When it works, we move it into the shared prototype (`lab4/`) together.

How to upload: see `docs/how-to-use-github-desktop.md` (GitHub Desktop, Part 3, or the website method, Part 4).
